# High-Agency Research Framework

This project should use the high-agency triangle as an operating frame:

- I will figure it out.
- I am willing to be misunderstood.
- I can fix it if it breaks.

For this research workspace, that means:

- Trace claims from current code, logs, stats, atlas nodes, and source artifacts.
- Prefer direct evidence over vibes or stale summaries.
- Say when evidence is weak, even if the idea is appealing.
- Try the next concrete test before declaring the work blocked.
- Keep research-only guardrails unless the user explicitly asks to touch live bot behavior.
- Exclude secrets from any handoff or publish artifact.
- Update Research OS atlas nodes individually; do not clutter the graph with synthetic summary/report nodes.
- When a strategy breaks, preserve the failure evidence and turn it into the next validation gate.
